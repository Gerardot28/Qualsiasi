# Materiale conservato per un sequel (Johto, Sinnoh, Unima, Kalos, Alola, Galar, Paldea)

Questa versione di Pokémon Multiverse copre **Hoenn (Atto 1) e Kanto (Atto 2)**.
Per un eventuale sequel con le altre regioni è già pronto:

- `tools/trainer_sprites/`: pipeline che ricrea 121 ritratti 64x64 (formato GBA) di Capipalestra,
  Superquattro, Campioni, Kahuna e professori di tutte le regioni (`fetch_sources.sh` + `build_set.py`).
  Attenzione alle licenze indicate nel README dello strumento prima di una pubblicazione.
- `tools/mapgen/`: prototipo di "compilatore di mappe" (renderer dei tileset, libreria di stamp)
  per costruire nuove regioni con i tileset esistenti.
- `docs/riferimenti/regioni.md`: nomi italiani di città, Capipalestra, Superquattro e Campioni
  di tutte le regioni (con livello di affidabilità).
- `docs/storia/bibbia.md`: lore del Multiverso e dei Varchi, pensata per proseguire oltre il Grande Varco.
